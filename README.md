# Loan Approval Prediction

## 📌 About the Project

This project uses machine learning to predict whether a loan application will be approved or rejected based on applicant information.

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Logistic Regression
- Jupyter Notebook

## 📊 Dataset

The dataset contains applicant information such as:

- Gender
- Marital Status
- Education
- Applicant Income
- Loan Amount
- Credit History
- Loan Status

## 🔄 Project Workflow

1. Load the dataset
2. Check and preprocess the data
3. Handle missing values
4. Convert categorical values into numerical values
5. Split the data into training and testing sets
6. Train a Logistic Regression model
7. Make predictions
8. Evaluate the model using accuracy and a confusion matrix

## 🤖 Machine Learning Model

Logistic Regression is used to predict the loan approval status.

## 📈 Evaluation

The model is evaluated using:

- Accuracy Score
- Confusion Matrix

## 📁 Files

- `loan_approval_prediction_clean.ipynb` — Jupyter Notebook containing the complete project workflow
- `loan_data.csv` — Dataset used for the project
